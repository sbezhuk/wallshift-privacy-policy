# WallShift — Privacy Policy

This repository hosts the official Privacy Policy for the iOS game **WallShift**, developed by Stepan Bezhuk.

## 🛡️ Policy Highlights
- **Zero Data Collection:** WallShift does not collect, track, store, sell, or transmit any user data or personal identifiers.
- **Age Rating 4+:** Family-friendly and safe for players of all ages, including children (fully compliant with COPPA and GDPR-K).
- **100% Local Storage:** Game progress (scores, coins, achievements, volume settings) is saved exclusively on the player's iOS device.
