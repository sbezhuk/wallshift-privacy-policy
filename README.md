# WallShift — Privacy Policy

This repository hosts the official Privacy Policy for the iOS game **WallShift**, developed by Stepan Bezhuk.

## 🌐 Live Web Version
The policy is publicly accessible via GitHub Pages at:
👉 **[https://sbezhuk.github.io/wallshift-privacy-policy/](https://sbezhuk.github.io/wallshift-privacy-policy/)**

Features:
- Dual-language support (English & Українська)
- Full compliance with Apple App Store Guidelines, GDPR, and CCPA
- Detailed disclosure of local data storage (`UserDefaults`) and third-party advertising services (Unity Ads)
- Mobile-responsive design
